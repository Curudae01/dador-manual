Dador de objetos

メニューから製品を提供するシステムです。ワールドにREZして使用することも、アバターに装着して使用することもできます。

使い始めるクイックリファレンス
設定可能なメニューREZ設置または装着オブジェクトとノートカード対応する一時オブジェクト

できること

  • 製品をインベントリへ渡す
  • 一時オブジェクトを装着して表示する
  • 一時オブジェクトと恒久コピーを組み合わせる
  • 複数ユーザーで利用する
  • 設定可能なアニメーションを使用する
  • 受け渡しメッセージを表示する

一致する項目がありません

別の検索語を試してください。

01

はじめに

内容を確認し、Dador を使用できる状態にします。

Dador の内容

次の4つのスクリプトは Dador 内に残しておく必要があります。

Dador_Main v1.4.1
Dador_Config_Productos v1.3.4
Dador_Anim_portador v1.3.1
Dador_Menu_Multiusuario v1.0.1

そのほかに Config Dador、Lista Autorizados、Dador が使用するアニメーション、登録済み製品、必要に応じて TEMP_ コンポーネントがあります。

名前は完全一致が必要です

メインのノートカード名は必ず Config Dador にしてください。ACCESO=LISTA を使用する場合、アクセス用ノートカード名は必ず Lista Autorizados にしてください。スクリプト名や TEMP_ コンポーネント名は変更しないでください。

初回起動

  1. オブジェクトを編集でき、スクリプトを実行できる場所に Dador のコピーをREZします。
  2. Dador を右クリックして Edit を選びます。
  3. Contents タブを開きます。
  4. 4つのメインスクリプトがすべて入っていることを確認します。
  5. Config Dador が入っていることを確認します。
  6. Config Dador に指定されているアニメーションが実際に Dador 内にあることを確認します。
  7. Config Dador を開き、このマニュアルで説明している項目だけを変更して保存します。
  8. テストする前に数秒待ちます。

Config Dador の保存、アニメーションや製品、TEMP_ コンポーネントの追加・削除など、インベントリが変更されるとシステムは自動的に再読み込みします。

02

Config Dador

スクリプトを編集せずに製品を設定するための中心となるノートカードです。

設定行は NOMBRE=VALOR の形式で記述します。コード例に表示されているパラメータ名は翻訳せず、そのまま使用してください。

NOMBRE=VALOR

ルール

  • 小数点にはピリオドを使用します: 1.2
  • 小数点としてカンマは使用しません: 1,2
  • # で始まる行はコメントです。
  • 空行も使用できます。
  • Config Dador は物理行で最大100行まで対応します。
最小構成の例
ACCESO=TODOS
MENUS_SIMULTANEOS=NO

RADIO_USO=5.0
DISTANCIA_ANEXADO=2.0
DISTANCIA_NO_ANEXADO=1.2

完全な設定例

ACCESO=TODOS

MENUS_SIMULTANEOS=NO

FRASE_DAR=
MENSAJE_AUTOMATICO=SI
DISTANCIA_MENSAJES=20

RADIO_USO=5.0
DISTANCIA_ANEXADO=2.0
DISTANCIA_NO_ANEXADO=1.2

ANIM_PORTAR=Anim_Portar
ANIM_SERVIR=Anim_Servir
ANIM_RECIBIR_ANEXADO=Anim_Recibir_anexado
ANIM_RECOGER_NO_ANEXADO=Anim_Recoger_no_anexado

DURACION_ANIM_SERVIR=5.0
DURACION_ANIM_RECIBIR_ANEXADO=5.0
DURACION_ANIM_RECOGER_NO_ANEXADO=5.0

RETARDO_APARICION_TEMP_ANEXADO=0
RETARDO_APARICION_TEMP_NO_ANEXADO=0
03

誰が使用できるか

4つのアクセスモードがあります。

TODOS

ACCESO=TODOS

すべてのアバターが Dador を使用できます。

PROPIETARIO

ACCESO=PROPIETARIO

所有者だけが使用できます。

GRUPO

ACCESO=GRUPO

Dador と同じグループをアクティブにしているアバターだけが使用できます。

LISTA

ACCESO=LISTA

Lista Autorizados に登録されたアバターだけが使用できます。

Lista Autorizados

Second Life の Username を1行につき1名記入します。Display Name は使用しないでください。

avatar.ejemplo
OtroUsuario

空行と # で始まるコメントを使用できます。最大20アバターです。Username を解決できない場合、修正されるまで LISTA モードはブロックされます。

04

単独メニューまたは同時メニュー

複数の人が利用するときの Dador の動作を選びます。

通常

MENUS_SIMULTANEOS=NO

同時に Dador を使用できるのは1人だけです。そのユーザーがメニュー操作、選択、受け取りを行っている間、別のユーザーには使用中であることが通知されます。

Dador が装着されている場合、このモードでは ANIM_SERVIR が通常どおり動作します。

マルチユーザー

MENUS_SIMULTANEOS=SI

複数のアバターが同時に自分専用のメニューを開いて操作できます。受け渡し処理はその後、順番に1件ずつ行われます。

上限は同時メニュー20件、待機中の受け渡し要求20件です。

同時モードでのアニメーション

Dador が装着されている場合、ANIM_SERVIR は再生されません。ANIM_PORTAR、受け取り側のアニメーション、一時オブジェクト、恒久コピーは引き続き動作します。

製品メニュー

  • 1ページに最大3製品を表示します。
  • ページが複数ある場合は Anterior と Siguiente を使用します。
  • Cancelar を含みます。
  • 各メニューは約30秒間操作がないと期限切れになります。
05

距離

メニューを開く距離と受け渡しを完了できる距離を、3つの値で個別に設定します。

RADIO_USO

0.5 .. 300.0 m

アバターが Dador の使用を開始してメニューを開ける最大距離です。

DISTANCIA_ANEXADO

0.1 .. 100.0 m

Dador 装着時に受け渡しを完了できる最大距離です。受け取り側と Dador を装着しているアバターの間を水平距離で測定します。

DISTANCIA_NO_ANEXADO

0.1 .. 100.0 m

Dador をREZして使用する場合の最終受け渡し距離です。オブジェクトの端から測定します。

必須ルール

DISTANCIA_ANEXADO と DISTANCIA_NO_ANEXADO は RADIO_USO より大きく設定できません。

有効

RADIO_USO=20.0
DISTANCIA_ANEXADO=15.0
DISTANCIA_NO_ANEXADO=10.0

無効

RADIO_USO=10.0
DISTANCIA_ANEXADO=15.0
06

アニメーション

インベントリ内の正確な名前で設定する、4つの独立した任意アニメーションです。

どのアニメーションも無効にできます

値を空にすると、そのアニメーションは再生されません。有効なアニメーションと無効なアニメーションを自由に組み合わせられます。

ANIM_PORTAR=
ANIM_SERVIR=
ANIM_RECIBIR_ANEXADO=
ANIM_RECOGER_NO_ANEXADO=

ANIM_PORTAR

Dador を装着しているアバターの常時ポーズです。使用する場合は loop 用に準備してください。空の場合、持つためのポーズは再生されません。

ANIM_PORTAR=Anim_Portar

ANIM_SERVIR

持つ側の一時的なサーブアニメーションです。Dador が装着され、MENUS_SIMULTANEOS=NO の場合だけ使用されます。空の場合、サーブアニメーションは再生されません。

ANIM_SERVIR=Anim_Servir
DURACION_ANIM_SERVIR=5.0

ANIM_RECIBIR_ANEXADO

Dador が装着されている場合の受け取り側アニメーションです。空にできます。

ANIM_RECIBIR_ANEXADO=Anim_Recibir_anexado
DURACION_ANIM_RECIBIR_ANEXADO=5.0

ANIM_RECOGER_NO_ANEXADO

Dador がREZされている場合の受け取り側アニメーションです。空にできます。

ANIM_RECOGER_NO_ANEXADO=Anim_Recoger_no_anexado
DURACION_ANIM_RECOGER_NO_ANEXADO=5.0

3つの一時アニメーション時間は引き続き 0.1 .. 60.0 秒です。対応するアニメーションが空の場合、その時間設定は単に無視されます。ANIM_PORTAR には時間設定はありません。

購入したアニメーションを使う

アニメーションを改名する必要はありません。ANIM_* の行に名前を指定する場合、そのアニメーションを Dador に入れ、インベントリの正確な名前を記入してください。行が空なら、その役割のアニメーションは不要です。

ANIM_RECIBIR_ANEXADO=[Tienda] Take Drink Bento 03

一時オブジェクトが表示されるタイミング

RETARDO_APARICION_TEMP_ANEXADO=1.3
RETARDO_APARICION_TEMP_NO_ANEXADO=1.6

受け取りアニメーションが有効な場合、遅延はそのアニメーション時間内に設定します。対応する受け取りアニメーションが空の場合、同期するアニメーションがないため、一時オブジェクトはすぐに表示され、この遅延は使用されません。

07

受け渡しメッセージ

任意の文章、自動メッセージ、または両方を使用できます。

FRASE_DAR

任意の文章を設定します。パラメータ名 FRASE_DAR は変更しないでください。

FRASE_DAR=Que aproveche!

任意の文章を表示しない場合は空のままにします。

FRASE_DAR=

MENSAJE_AUTOMATICO

自動受け渡しメッセージを有効にする場合は SI、無効にする場合は NO を使用します。Config Dador 内の SI/NO は翻訳しないでください。

MENSAJE_AUTOMATICO=SI

SI の場合、Dador は次の形式のメッセージを追加します。

<Nombre del Dador> te ha dado <Nombre del producto>.
FRASE_DAR自動結果
空NOメッセージなし
空SI自動のみ
文章ありNO任意文のみ
文章ありSI任意文 + 自動

DISTANCIA_MENSAJES

10ささやき · 約10 m
20通常チャット · 約20 m
100叫び · 約100 m
Dador の名前が2回表示される理由

Second Life は発言したオブジェクト名を自動的に表示します。自動メッセージ側にも同じオブジェクト名が含まれるため、2回表示される場合があります。

08

製品を追加

Dador は、あらかじめ対応するよう準備された製品を使用する設計です。

  1. Dador をREZします。
  2. 編集して Contents を開きます。
  3. 準備済みの製品を Dador の中へ入れます。
  4. TEMP_ コンポーネントがある場合は、それも一緒に入れます。
  5. 名前、説明、スクリプト、アニメーション、内部コンテンツを変更しないでください。
  6. カタログが再読み込みされるまで数秒待ちます。
  7. Dador にタッチし、製品がメニューに表示されることを確認します。
30最大製品数
128インベントリ総数の上限
互換性

通常の Second Life オブジェクトすべてが自動的に Dador 対応になるわけではありません。

09

一時オブジェクトと TEMP_

受け渡し中に装着表示できる視覚用の製品です。

準備済み製品の中には、名前が正確に TEMP_ で始まる関連オブジェクトを含むものがあります。

Nota de demostración
TEMP_Nota de demostración

メイン製品はメニューに表示されます。TEMP_ 要素は内部用で、独立した製品としては表示されません。

一時オブジェクトでできること

  • アニメーション終了後に自動的に消える。
  • 1つ以上の専用アニメーションを実行する。
  • シーケンス終了後も装着したまま残る。
  • アバターが手動で外すまで装着したまま残る。

ビールのデモ

準備済みのビールを Dador に入れ、名前や説明を変更せず、再読み込みを待ってからメニューで選択します。

ノートカード + TEMP_

ノートカードと関連する TEMP_ オブジェクトの両方を、名前を変更せずに入れます。メニューにはノートカードが表示され、TEMP_ コンポーネントは表示されません。

10

REZ設置・装着での使用

同じシステムを2通りの方法で使用できます。

REZ設置
  1. Dador をワールドに設置します。
  2. ユーザーは RADIO_USO の範囲内にいる必要があります。
  3. Dador にタッチして製品を選択します。
  4. 受け渡しを完了するには DISTANCIA_NO_ANEXADO の範囲内にいる必要があります。
  5. 受け取り側は ANIM_RECOGER_NO_ANEXADO を使用します。

REZ設置モードでは ANIM_PORTAR と ANIM_SERVIR は使用されません。

装着
  1. 製品を渡す側のアバターに Dador を装着します。
  2. ANIM_PORTAR が自動的に開始します。
  3. 別のアバターが Dador にタッチして製品を選択します。
  4. 受け取り側は DISTANCIA_ANEXADO の範囲内にいる必要があります。
  5. 受け取り側は ANIM_RECIBIR_ANEXADO を使用します。

MENUS_SIMULTANEOS=NO の場合、持つ側では ANIM_SERVIR も再生されます。

持っている本人には渡せません

Dador を装着しているアバターは、装着中に自分自身の Dador を利用できません。他のアバターへ製品を渡すための仕様です。

11

トラブルシューティング

よくある問題の多くは、次の確認で解決できます。

メニューが表示されない

RADIO_USO、ACCESO モード、Dador の読み込み完了、有効な製品の存在、Config Dador にエラーがないことを確認してください。

「アクセス不可」と表示される

GRUPO の場合は Dador のグループとアバターのアクティブグループを確認します。LISTA の場合は Display Name ではなく有効な Username を使用します。

Dador が使用中と表示される

MENUS_SIMULTANEOS=NO では正常です。同時に1人だけが使用できます。

メニューまたは要求が多すぎる

同時モードでは、アクティブなメニューセッションは最大20件、待機中の選択は最大20件です。

もっと近づくよう表示される

RADIO_USO の範囲内でも、最終受け渡し距離の外にいる場合があります。DISTANCIA_ANEXADO または DISTANCIA_NO_ANEXADO を確認してください。

アニメーションが再生されない

アニメーションが Dador 内にあり、名前が完全一致し、設定時間が正しいことを確認してください。ANIM_PORTAR は loop 用に準備されたアニメーションである必要があります。

ANIM_SERVIR が再生されない

MENUS_SIMULTANEOS=SI の場合は仕様どおりです。

一時オブジェクトの表示が早すぎる、または遅すぎる

RETARDO_APARICION_TEMP_ANEXADO または RETARDO_APARICION_TEMP_NO_ANEXADO を調整してください。

一時オブジェクトが消えない

正常な場合があります。一部の製品は受け取り側が手動で外すまで装着したままになるよう設計されています。

受け渡しメッセージが表示されない

FRASE_DAR= と MENSAJE_AUTOMATICO=NO の場合、何も表示されないのが正しい動作です。

DISTANCIA_MENSAJES でエラーになる

使用できる値は 10、20、100 だけです。
