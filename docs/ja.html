Delivery

メニューから製品を提供するシステムです。ワールドにREZして使用することも、アバターに装着して使用することもできます。

使い始めるクイックリファレンス
設定可能なメニューREZ設置または装着オブジェクトとノートカード対応する一時オブジェクト

できること

  • 製品をインベントリへ渡す
  • 一時オブジェクトを装着して表示する
  • 一時オブジェクトと恒久コピーを組み合わせる
  • 複数ユーザーで利用する
  • 設定可能なアニメーションを使用する
  • 受け渡しメッセージを表示する

一致する項目がありません

別の検索語を試してください。

01

はじめに

内容を確認し、Dador を使用できる状態にします。

Dador の内容

次の4つのスクリプトは Dador 内に残しておく必要があります。

Dador_Main v1.4.1
Dador_Config_Products v1.3.4
Dador_Carrier_Animation v1.3.1
Dador_Multiuser_Menu v1.0.1

そのほかに Dador Config、Authorized Users、Dador が使用するアニメーション、登録済み製品、必要に応じて TEMP_ コンポーネントがあります。

名前は完全一致が必要です

メインのノートカード名は必ず Dador Config にしてください。ACCESS=LIST を使用する場合、アクセス用ノートカード名は必ず Authorized Users にしてください。スクリプト名や TEMP_ コンポーネント名は変更しないでください。

初回起動

  1. オブジェクトを編集でき、スクリプトを実行できる場所に Dador のコピーをREZします。
  2. Dador を右クリックして Edit を選びます。
  3. Contents タブを開きます。
  4. 4つのメインスクリプトがすべて入っていることを確認します。
  5. Dador Config が入っていることを確認します。
  6. Dador Config に指定されているアニメーションが実際に Dador 内にあることを確認します。
  7. Dador Config を開き、このマニュアルで説明している項目だけを変更して保存します。
  8. テストする前に数秒待ちます。

Dador Config の保存、アニメーションや製品、TEMP_ コンポーネントの追加・削除など、インベントリが変更されるとシステムは自動的に再読み込みします。

02

Dador Config

スクリプトを編集せずに製品を設定するための中心となるノートカードです。

設定行は NOMBRE=VALOR の形式で記述します。コード例に表示されているパラメータ名は翻訳せず、そのまま使用してください。

NOMBRE=VALOR

ルール

  • 小数点にはピリオドを使用します: 1.2
  • 小数点としてカンマは使用しません: 1,2
  • # で始まる行はコメントです。
  • 空行も使用できます。
  • Dador Config は物理行で最大100行まで対応します。
最小構成の例
ACCESS=ALL
SIMULTANEOUS_MENUS=NO

USE_RADIUS=5.0
ATTACHED_DISTANCE=2.0
REZZED_DISTANCE=1.2

完全な設定例

ACCESS=ALL

SIMULTANEOUS_MENUS=NO

DELIVERY_MESSAGE=
AUTOMATIC_MESSAGE=YES
MESSAGE_DISTANCE=20

USE_RADIUS=5.0
ATTACHED_DISTANCE=2.0
REZZED_DISTANCE=1.2

CARRY_ANIMATION=Anim_Carry
SERVE_ANIMATION=Anim_Serve
ATTACHED_RECEIVE_ANIMATION=Anim_Receive_Attached
REZZED_PICKUP_ANIMATION=Anim_Pickup_Rezzed

SERVE_ANIMATION_DURATION=5.0
ATTACHED_RECEIVE_ANIMATION_DURATION=5.0
REZZED_PICKUP_ANIMATION_DURATION=5.0

ATTACHED_TEMP_SHOW_DELAY=0
REZZED_TEMP_SHOW_DELAY=0
03

誰が使用できるか

4つのアクセスモードがあります。

ALL

ACCESS=ALL

すべてのアバターが Dador を使用できます。

OWNER

ACCESS=OWNER

所有者だけが使用できます。

GROUP

ACCESS=GROUP

Dador と同じグループをアクティブにしているアバターだけが使用できます。

LIST

ACCESS=LIST

Authorized Users に登録されたアバターだけが使用できます。

Authorized Users

Second Life の Username を1行につき1名記入します。Display Name は使用しないでください。

avatar.ejemplo
OtroUsuario

空行と # で始まるコメントを使用できます。最大20アバターです。Username を解決できない場合、修正されるまで LIST モードはブロックされます。

04

単独メニューまたは同時メニュー

複数の人が利用するときの Dador の動作を選びます。

通常

SIMULTANEOUS_MENUS=NO

同時に Dador を使用できるのは1人だけです。そのユーザーがメニュー操作、選択、受け取りを行っている間、別のユーザーには使用中であることが通知されます。

Dador が装着されている場合、このモードでは SERVE_ANIMATION が通常どおり動作します。

マルチユーザー

SIMULTANEOUS_MENUS=YES

複数のアバターが同時に自分専用のメニューを開いて操作できます。受け渡し処理はその後、順番に1件ずつ行われます。

上限は同時メニュー20件、待機中の受け渡し要求20件です。

同時モードでのアニメーション

Dador が装着されている場合、SERVE_ANIMATION は再生されません。CARRY_ANIMATION、受け取り側のアニメーション、一時オブジェクト、恒久コピーは引き続き動作します。

製品メニュー

  • 1ページに最大3製品を表示します。
  • ページが複数ある場合は Previous と Next を使用します。
  • Cancel を含みます。
  • 各メニューは約30秒間操作がないと期限切れになります。
05

距離

メニューを開く距離と受け渡しを完了できる距離を、3つの値で個別に設定します。

USE_RADIUS

0.5 .. 300.0 m

アバターが Dador の使用を開始してメニューを開ける最大距離です。

ATTACHED_DISTANCE

0.1 .. 100.0 m

Dador 装着時に受け渡しを完了できる最大距離です。受け取り側と Dador を装着しているアバターの間を水平距離で測定します。

REZZED_DISTANCE

0.1 .. 100.0 m

Dador をREZして使用する場合の最終受け渡し距離です。オブジェクトの端から測定します。

必須ルール

ATTACHED_DISTANCE と REZZED_DISTANCE は USE_RADIUS より大きく設定できません。

有効

USE_RADIUS=20.0
ATTACHED_DISTANCE=15.0
REZZED_DISTANCE=10.0

無効

USE_RADIUS=10.0
ATTACHED_DISTANCE=15.0
06

アニメーション

インベントリ内の正確な名前で設定する、4つの独立した任意アニメーションです。

どのアニメーションも無効にできます

値を空にすると、そのアニメーションは再生されません。有効なアニメーションと無効なアニメーションを自由に組み合わせられます。

CARRY_ANIMATION=
SERVE_ANIMATION=
ATTACHED_RECEIVE_ANIMATION=
REZZED_PICKUP_ANIMATION=

CARRY_ANIMATION

Dador を装着しているアバターの常時ポーズです。使用する場合は loop 用に準備してください。空の場合、持つためのポーズは再生されません。

CARRY_ANIMATION=Anim_Carry

SERVE_ANIMATION

持つ側の一時的なサーブアニメーションです。Dador が装着され、SIMULTANEOUS_MENUS=NO の場合だけ使用されます。空の場合、サーブアニメーションは再生されません。

SERVE_ANIMATION=Anim_Serve
SERVE_ANIMATION_DURATION=5.0

ATTACHED_RECEIVE_ANIMATION

Dador が装着されている場合の受け取り側アニメーションです。空にできます。

ATTACHED_RECEIVE_ANIMATION=Anim_Receive_Attached
ATTACHED_RECEIVE_ANIMATION_DURATION=5.0

REZZED_PICKUP_ANIMATION

Dador がREZされている場合の受け取り側アニメーションです。空にできます。

REZZED_PICKUP_ANIMATION=Anim_Pickup_Rezzed
REZZED_PICKUP_ANIMATION_DURATION=5.0

3つの一時アニメーション時間は引き続き 0.1 .. 60.0 秒です。対応するアニメーションが空の場合、その時間設定は単に無視されます。CARRY_ANIMATION には時間設定はありません。

購入したアニメーションを使う

アニメーションを改名する必要はありません。ANIM_* の行に名前を指定する場合、そのアニメーションを Dador に入れ、インベントリの正確な名前を記入してください。行が空なら、その役割のアニメーションは不要です。

ATTACHED_RECEIVE_ANIMATION=[Tienda] Take Drink Bento 03

一時オブジェクトが表示されるタイミング

ATTACHED_TEMP_SHOW_DELAY=1.3
REZZED_TEMP_SHOW_DELAY=1.6

受け取りアニメーションが有効な場合、遅延はそのアニメーション時間内に設定します。対応する受け取りアニメーションが空の場合、同期するアニメーションがないため、一時オブジェクトはすぐに表示され、この遅延は使用されません。

07

受け渡しメッセージ

任意の文章、自動メッセージ、または両方を使用できます。

DELIVERY_MESSAGE

任意の文章を設定します。パラメータ名 DELIVERY_MESSAGE は変更しないでください。

DELIVERY_MESSAGE=Que aproveche!

任意の文章を表示しない場合は空のままにします。

DELIVERY_MESSAGE=

AUTOMATIC_MESSAGE

自動受け渡しメッセージを有効にする場合は YES、無効にする場合は NO を使用します。Dador Config 内の YES/NO は翻訳しないでください。

AUTOMATIC_MESSAGE=YES

YES の場合、Dador は次の形式のメッセージを追加します。

<Dador name> has given you <Product name>.
DELIVERY_MESSAGE自動結果
空NOメッセージなし
空YES自動のみ
文章ありNO任意文のみ
文章ありYES任意文 + 自動

MESSAGE_DISTANCE

10ささやき · 約10 m
20通常チャット · 約20 m
100叫び · 約100 m
Dador の名前が2回表示される理由

Second Life は発言したオブジェクト名を自動的に表示します。自動メッセージ側にも同じオブジェクト名が含まれるため、2回表示される場合があります。

08

製品を作成して追加する

Dador に対応するオブジェクトまたは notecard をゼロから準備する方法です。

必要なもの

通常のコピーだけを配布する場合は、製品本体と説明欄を準備すれば十分です。製品に一時コンポーネントが必要な場合は、システムに付属する Temporary_Script と、必要に応じて名前が完全に Temporary Config の notecard を使用します。このマニュアルでは設定方法を説明します。スクリプトコードを編集する必要はありません。

1. 製品が何を渡すか決める

Dador はメイン要素の説明欄を読み、2つの指定を使用します。T は一時部分、C は恒久コピーです。

説明結果代表的な用途
TEMP=NO;COPY=YES恒久コピーのみオブジェクトまたは notecard をインベントリへ渡す
TEMP=YES;COPY=NO一時オブジェクトのみ一時的に装着され、コピーを残さない prop
TEMP=YES;COPY=YES一時 + 恒久コピー一時シーンとインベントリへのコピーを両方使用

説明欄が空の場合は TEMP=NO;COPY=YES と同じ扱いです。TEMP=NO;COPY=NO は使用しないでください。渡すものが何もないため Dador は無効と判断します。

2. 製品構成を選ぶ

コピー用オブジェクト

Beer
Description: TEMP=NO;COPY=YES

Temporary_Script は不要です。

一時オブジェクト

Beer
Description: TEMP=YES;COPY=NO

TEMP_Beer が存在しない場合、メインオブジェクト自身を一時オブジェクトとして使用できます。

オブジェクト + TEMP_

Beer
TEMP_Beer

TEMP_Beer が存在する場合、Dador はそれを一時コンポーネントとして優先します。メニューに表示される製品は Beer のままです。

Notecard + TEMP_

Beer recipe
TEMP_Beer recipe

T=YES の notecard では TEMP_<正確な名前> のオブジェクトが必須です。

3. 一時オブジェクトを準備する

一時コンポーネントとして動作するオブジェクトには、一時用の中核と、必要に応じて設定とアニメーションを入れます。

Temporary_Script
Temporary Config
独自アニメーション（任意）
名前は完全一致

notecard の名前は必ず完全に Temporary Config にしてください。TEMP_ プレフィックスもそのまま使用し、その後ろにメイン製品の完全な名前を続けます。

TEMP/COPY の設定はメイン製品の説明欄に書きます。別の TEMP_ 補助オブジェクトを使う場合、その補助側の説明欄に同じ設定を重複して書く必要はありません。Dador はメイン製品の設定を使用します。

4. Temporary Config を設定する

一般パラメータは ANIMATIONn/DURATIONn シーケンスを始める前に記述します。

一時オブジェクトに独自アニメーションがなく、終了動作が既定の DETACH_AT_END=YES で、独自の受け取りメッセージも不要なら Temporary Config は省略できます。DETACH_AT_END=NO で装着を維持する場合、PICKUP_MESSAGE を使う場合、またはシーケンスを制御する場合は Temporary Config が必要です。

Temporary Config は最大 100物理行です。時間の小数にはピリオドを使用します。例: 4.2。

独自アニメーションなし

PICKUP_MESSAGE=
MESSAGE_DISTANCE=20
DETACH_AT_END=YES

ANIMATION1=
DURATION1=

アニメーション1つ

PICKUP_MESSAGE=ビールを受け取りました。
MESSAGE_DISTANCE=20
DETACH_AT_END=NO

ANIMATION1=ARM PICKUP
DURATION1=4.2

PICKUP_MESSAGE

一時オブジェクト自身が attach の約1秒後に発言するテキストです。空欄なら発言しません。

MESSAGE_DISTANCE

10、20、100 のみ使用できます。省略時は 20 です。

DETACH_AT_END

YES は終了時に一時オブジェクトを非表示にして解除します。NO はアバターが自分で外すまで表示・装着を維持します。

ANIMATIONn / DURATIONn

最大10個。1から連番で指定します。実際の各時間は 0.1〜60.0 秒です。

同じキーが2つの異なる notecard で使われます

MESSAGE_DISTANCE は Temporary Config と Dador Config の両方で有効です。それぞれの notecard が独立したメッセージ距離を制御します。

5. 一時アニメーションのルール

  • ペアは連続して記述します。ANIMATION1 + DURATION1、次に ANIMATION2 + DURATION2 の順です。
  • アニメーションと時間の間に PICKUP_MESSAGE、MESSAGE_DISTANCE、DETACH_AT_END を挟まないでください。
  • 名前は一時オブジェクト内のアニメーション名と完全に一致させます。
  • ANIMATION1= + DURATION1= のような空ペアはシーケンスを明示的に終了し、インベントリに未使用アニメーションが残っていても何も実行しない設定にできます。
  • 空ペアの後に新しいアニメーションを追加しないでください。

6. 権限を確認する

Dador はコピー配布と一時オブジェクト生成に必要な権限を確認します。一時用に使う要素は、それと一緒に移動する必要がある内容も含めて Copy + Transfer を許可する必要があります。準備後に権限を変更した場合は、完全なテストをやり直してください。

7. Dador に入れる前に製品をテストする

Temporary_Script v2.6.4 を使う場合、一時オブジェクトを手動で REZ します。Dador の起動データを受け取らないため準備モードになり、装着、権限要求、アニメーション実行、自動削除は行いません。

診断は TEMP/COPY 説明、Temporary Config、各パラメータ、アニメーション、製品全体の状態を確認します。すべて正しければ次のような表示になります。

OK: TEMP=YES;COPY=YES (temporary + copy).
PREP v2.6.4 | objeto='Pepo' | anim=1 | secuencia=1
RESULT: READY to be placed in the Dador.
MEM: usada=... libre=...

RESULT: NOT READY が表示された場合は、示されたエラーを先に修正してください。インベントリ変更時には診断が再実行され、準備モード中は名前と説明も監視されます。

8. 製品を Dador に入れる

  1. 診断で RESULT: READY が表示されたら、REZしていたオブジェクトを取り戻します。
  2. Dador を編集して Contents を開きます。
  3. メイン製品を追加します。
  4. 別の TEMP_ コンポーネントを使う場合は、それも追加します。
  5. テスト済みの名前、説明、スクリプト、notecard、アニメーション、権限は変更しません。
  6. カタログが再読み込みされるまで数秒待ちます。
  7. Dador にタッチし、メイン製品がメニューに表示されることを確認します。
  8. 実際に配布し、一時部分と恒久コピーの両方を必要に応じて確認します。
30最大製品数
128インベントリ総数の上限
簡単なまとめ

最初に TEMP/COPY を決めます。一時部分がある場合はそれを準備し、Temporary Config を設定して REZ し、RESULT: READY を確認します。その後で製品と必要な TEMP_ を Dador に入れ、完全な配布テストを行います。

09

一時オブジェクトと TEMP_

受け渡し中に装着表示できる視覚用の製品です。

準備済み製品の中には、名前が正確に TEMP_ で始まる関連オブジェクトを含むものがあります。

Nota de demostración
TEMP_Nota de demostración

メイン製品はメニューに表示されます。TEMP_ 要素は内部用で、独立した製品としては表示されません。

一時オブジェクトでできること

  • アニメーション終了後に自動的に消える。
  • 1つ以上の専用アニメーションを実行する。
  • シーケンス終了後も装着したまま残る。
  • アバターが手動で外すまで装着したまま残る。

ビールのデモ

準備済みのビールを Dador に入れ、名前や説明を変更せず、再読み込みを待ってからメニューで選択します。

ノートカード + TEMP_

ノートカードと関連する TEMP_ オブジェクトの両方を、名前を変更せずに入れます。メニューにはノートカードが表示され、TEMP_ コンポーネントは表示されません。

10

REZ設置・装着での使用

同じシステムを2通りの方法で使用できます。

REZ設置
  1. Dador をワールドに設置します。
  2. ユーザーは USE_RADIUS の範囲内にいる必要があります。
  3. Dador にタッチして製品を選択します。
  4. 受け渡しを完了するには REZZED_DISTANCE の範囲内にいる必要があります。
  5. 受け取り側は REZZED_PICKUP_ANIMATION を使用します。

REZ設置モードでは CARRY_ANIMATION と SERVE_ANIMATION は使用されません。

装着
  1. 製品を渡す側のアバターに Dador を装着します。
  2. CARRY_ANIMATION が自動的に開始します。
  3. 別のアバターが Dador にタッチして製品を選択します。
  4. 受け取り側は ATTACHED_DISTANCE の範囲内にいる必要があります。
  5. 受け取り側は ATTACHED_RECEIVE_ANIMATION を使用します。

SIMULTANEOUS_MENUS=NO の場合、持つ側では SERVE_ANIMATION も再生されます。

持っている本人には渡せません

Dador を装着しているアバターは、装着中に自分自身の Dador を利用できません。他のアバターへ製品を渡すための仕様です。

11

トラブルシューティング

よくある問題の多くは、次の確認で解決できます。

メニューが表示されない

USE_RADIUS、ACCESS モード、Dador の読み込み完了、有効な製品の存在、Dador Config にエラーがないことを確認してください。

「アクセス不可」と表示される

GROUP の場合は Dador のグループとアバターのアクティブグループを確認します。LIST の場合は Display Name ではなく有効な Username を使用します。

Dador が使用中と表示される

SIMULTANEOUS_MENUS=NO では正常です。同時に1人だけが使用できます。

メニューまたは要求が多すぎる

同時モードでは、アクティブなメニューセッションは最大20件、待機中の選択は最大20件です。

もっと近づくよう表示される

USE_RADIUS の範囲内でも、最終受け渡し距離の外にいる場合があります。ATTACHED_DISTANCE または REZZED_DISTANCE を確認してください。

アニメーションが再生されない

アニメーションが Dador 内にあり、名前が完全一致し、設定時間が正しいことを確認してください。CARRY_ANIMATION は loop 用に準備されたアニメーションである必要があります。

SERVE_ANIMATION が再生されない

SIMULTANEOUS_MENUS=YES の場合は仕様どおりです。

一時オブジェクトの表示が早すぎる、または遅すぎる

ATTACHED_TEMP_SHOW_DELAY または REZZED_TEMP_SHOW_DELAY を調整してください。

一時オブジェクトが消えない

正常な場合があります。一部の製品は受け取り側が手動で外すまで装着したままになるよう設計されています。

受け渡しメッセージが表示されない

DELIVERY_MESSAGE= と AUTOMATIC_MESSAGE=NO の場合、何も表示されないのが正しい動作です。

MESSAGE_DISTANCE でエラーになる

使用できる値は 10、20、100 だけです。
